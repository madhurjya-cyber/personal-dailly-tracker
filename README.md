# DailyScore

A personal daily habit and productivity tracker with daily, weekly, and
monthly performance scoring.

## Overview

DailyScore allows users to record their daily performance across customizable
activities and converts those records into daily, weekly, and monthly
statistics.

The daily interface resets automatically when a new day begins while
historical records remain preserved.

## Features

- Daily activity tracking
- 0–10 scoring system
- Automatic daily score calculation
- Automatic daily reset
- Persistent historical records
- Add, rename, and remove activities
- Weekly performance statistics
- Monthly performance statistics
- Offline-first local storage
- Responsive personal dashboard

## Technology
